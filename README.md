# appinfo

Privacy policies and support pages for my apps, served by GitHub Pages at https://usernameistony.github.io/appinfo/.

Each app gets its own folder with `privacy/` and `support/`; plain HTML sharing `style.css`, no build step.

| App | Support | Privacy |
|---|---|---|
| Katahdin (iPhone) | `/appinfo/katahdin/support/` | `/appinfo/katahdin/privacy/` |

The URLs are entered in App Store Connect, so don't rename or move these folders.
